# Shadow Unit Frames - Single

Shadowed Unit Frames for **WotLK 3.3.5a** with a `[paragon]` tag for **SingleWoW**.

Requires the **SingleWoW** addon. Paragon is **player frame only**. The number comes from the official Paragon Board (`SWBoard` / the green **PARAGON 9** label). Shows `0` until that value is known.

## Install

Download **Shadow.Unit.Frames.Single.1.2.zip** from [Releases](https://github.com/SultonMRP/Shadow-Unit-Frames-Single/releases) and extract it into `Interface\AddOns` so you have:

`Interface\AddOns\ShadowedUnitFrames\ShadowedUnitFrames.toc`  
`Interface\AddOns\ShadowedUF_Options\ShadowedUF_Options.toc`

Then `/reload`.

## Use

`/suf` → **Player** → **Text/Tags** → **Paragon** or **Paragon (#)**.

```
[paragon]     → 9
[()paragon]   → (9)
```

Neither tag adds a space.
